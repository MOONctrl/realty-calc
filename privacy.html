Оператор не является индивидуальным предпринимателем или юридическим лицом. Обработка персональных данных осуществляется для личных нужд — предоставления функционала калькулятора недвижимости.

2. Какие данные собираются

2.1. На Сайте собираются и обрабатываются следующие данные:

  • Параметры расчёта: стоимость недвижимости, срок ипотеки, процентная ставка, сумма аренды, выбранные льготы — все данные вводятся пользователем и не сохраняются на сервере;
  • Технические данные (обезличенно): IP-адрес, тип браузера, данные о посещениях — обрабатываются сервисом Яндекс.Метрика в обезличенном виде;
  • Cookie-файлы: используются для работы сайта и сбора статистики (хранятся до 1 года).

2.2. Оператор НЕ СОБИРАЕТ и НЕ ОБРАБАТЫВАЕТ следующие данные: фамилия, имя, отчество, адрес электронной почты, номера телефонов, паспортные данные, банковские реквизиты.

3. Цель обработки данных

Обработка персональных данных осуществляется исключительно для предоставления пользователю функционала ипотечного калькулятора: расчёта ежемесячных платежей, переплаты, сравнения с арендой, оценки доходности и налогов.

4. Правовое основание обработки

Обработка персональных данных осуществляется на основании:

  • Федерального закона от 27.07.2006 № 152-ФЗ «О персональных данных» (п. 2 ст. 22 — освобождение для физлиц);
  • Согласия пользователя, выраженного путём проставления галочки перед нажатием кнопки «Рассчитать» (есть на всех страницах калькулятора).

5. Cookie-файлы

5.1. Сайт использует файлы cookie для обеспечения работоспособности и сбора статистики.

5.2. Типы используемых cookie:

  • Технические cookie: необходимы для работы сайта (сессионные — удаляются после закрытия браузера);
  • Аналитические cookie: используются Яндекс.Метрикой для сбора статистики (хранятся до 1 года).

5.3. Пользователь может удалить cookie через настройки браузера или отключить их в любой момент.

5.4. Подробнее о cookie Яндекс.Метрики: https://yandex.ru/legal/confidential/

6.1. Все расчёты производятся локально на устройстве пользователя. Персональные данные НЕ СОХРАНЯЮТСЯ на сервере Оператора.

6.2. Персональные данные НЕ ПЕРЕДАЮТСЯ третьим лицам. Единственное исключение — обезличенные данные в Яндекс.Метрику (в соответствии с их политикой конфиденциальности).

6.3. Трансграничная передача персональных данных НЕ ОСУЩЕСТВЛЯЕТСЯ.
